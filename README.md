# EventHub

EventHub is a full-stack technology conference and event management platform.

## Core Features

- Attendee and organizer portals
- User authentication and role-based access
- Event creation and discovery
- Interactive seat selection
- Real-time seat availability
- Ticket booking and simulated payment
- QR code ticket generation
- Organizer analytics and attendee management
- QR check-in
- Ticket cancellation and refund simulation

## Technology Stack

- React 18 and Vite
- Tailwind CSS
- Node.js and Express.js
- MongoDB and Mongoose
- JWT and bcrypt
- Socket.IO
- Zustand and React Query
- Jest and Supertest

## Project Structure

- frontend/ - React frontend
- backend/ - Express backend
